# PRChain — Patient Record Management System

Blockchain-based patient record system developed for HealthCare Innovations Ltd.

## Stack
- Python 3.12.12 — custom blockchain prototype
- Solidity 0.8.19 — smart contract
- Hardhat 2.28.6 — testing framework
- Ethereum Sepolia Testnet — deployment
